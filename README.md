# ❤️ Heart Disease Prediction using Machine Learning

A Machine Learning project that predicts the likelihood of heart disease using Logistic Regression. The project is implemented in Python using Scikit-learn and trained on a heart disease dataset.

---

## 📌 Project Overview

Heart disease is one of the leading causes of death worldwide. This project demonstrates how Machine Learning can assist in predicting heart disease based on patient medical information.

The model is trained using Logistic Regression and can classify whether a patient is likely to have heart disease.

---

## 🚀 Features

- Data preprocessing and exploration
- Train/Test split
- Logistic Regression model
- Model evaluation using Accuracy Score
- Predict heart disease for new patient data
- Simple and beginner-friendly implementation

---

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

---

## 📂 Dataset

The project uses a Heart Disease dataset containing patient medical information such as:

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Maximum Heart Rate
- Exercise-Induced Angina
- ST Depression
- Number of Major Vessels
- Target (Heart Disease)

---

## 📊 Machine Learning Workflow

1. Import Libraries
2. Load Dataset
3. Data Exploration
4. Split Features & Target
5. Train/Test Split
6. Train Logistic Regression Model
7. Evaluate Accuracy
8. Predict New Patient Data

---

## 📈 Model Performance

The model is evaluated using **Accuracy Score** on the testing dataset.
